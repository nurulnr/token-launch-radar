How the value is worked out

Implied value = TVL × growth × age × chains

  • Growth — 1 + the 7-day TVL change, clamped to −40% … +150%. No change reported counts as 1.
  • Age — 1 + 0.12 × years tracked, up to 4 years. No start date on record counts as 0 years.
  • Chains — 1 + 0.04 × chains live, up to 6. More chains, more reach.
  • TVL — the base. Total value locked, as the snapshot reports it.

The implied value is this radar's own claim: what the token would be worth if the protocol's record stayed as it is. It is not a price, a prediction or investment advice. Every figure comes from the snapshot alone; no name list, no outside data.
